# GitHub Pages website

1. Extract this ZIP. Upload the docs folder to your GitHub repository, with index.html inside docs.
2. In Settings → Pages, choose Deploy from a branch, then main and /docs, and save.
3. Open the Pages URL shown by GitHub when deployment finishes.

Links work for both account sites and repository project sites. The opening animation appears only on the homepage.

The estimate form is in preview mode and does not send email. GitHub Pages cannot execute PHP. Connect an external form service before accepting estimate requests. The separate standard website package includes the PHP handler for PHP-capable hosting.
